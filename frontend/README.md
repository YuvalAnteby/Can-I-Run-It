# Frontend (Vite + React + TypeScript)

This frontend is built with Vite.

## Available Scripts

Run these commands from the frontend workspace:

- `npm run dev` — starts Vite dev server (default port `3000` in this project)
- `npm run start` — alias for `npm run dev`
- `npm run build` — creates a production build in `dist/`
- `npm run preview` — serves the production build locally
- `npm run test` — runs tests once with Vitest
- `npm run test:watch` — runs tests in watch mode with Vitest
- `npm run lint` — runs ESLint with autofix
